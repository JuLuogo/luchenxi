# 课堂积分系统

面向中职/高中公开课的**课堂积分 + 题库组卷 + 随机点名 + 学情分析 + 多端协同**系统。

- **网页版（v3，现在就能用）**：零构建静态页面 + 教师机上的本地枢纽进程，**不需要任何公网服务器**。
- **客户端版（v4，代码就位待编译）**：教师端桌面 App + 学生端 Android App，**数据落教师机本地 SQLite**，内置枢纽，并把 **EasyTier 组网**缝进应用；界面与网页版共用同一套代码。规划见 [docs/11](docs/11-跨平台客户端与数据库方案.md)，构建方式见 [apps/README.md](apps/README.md)，**完成度逐条对照（含"待外部条件"清单）见 [docs/12](docs/12-v4验收对照.md)**。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 按题型加权加分 | 基础题 **+3** / 拔高题 **+5** / 扩展题 **+8** / 提升题 **+10**，权重可改；单题可自定义分值；答对/部分正确/答错/跳过四档判定，支持抢答加分与答错扣分 |
| 题库 | 题干、**选项（选择题）**、答案、题型、分值、知识点、来源、备注；搜索/筛选/排序；JSON / CSV / 文本批量导入；导出与模板 |
| 组卷答题 | 「一套题」= 从题库勾选的若干题；逐题判定记分、调整顺序、当前题放大显示、逐条流水可撤销、本套题小结与 CSV 导出 |
| 学生小组端 | 手机/平板**按队伍入座**：抢答、点选作答、填空、主观题上报；本组看板、个人学情、排行榜；`?view=board` 变小组公屏 |
| 自动判分 | 选择题自动判分（多选漏选算部分正确）、填空题归一化比对、**主观题进教师端「待确认」由老师一键判定** |
| 点名系统 | 轮次池均匀 / 纯随机 / 最少被点优先；限定队伍、防连点、排除当前题已作答；姓名滚动动画；点完即可判分 |
| 学情分析 | 按题型与知识点统计作答数/正确率/**加权得分率**；自动识别薄弱与优势题型；个人报告 + 班级小结自动生成文字总结；导出 CSV / txt |
| 多端实时协同 | 教师端推题 → 学生抢答/作答 → 即时加分 → 大屏与学生端同步；在线小组、抢答榜、课堂实时流 |
| 数据安全 | 全部操作留日志；一键导出/导入全量备份；撤销上一步；归零保留历史；教师端换设备可从枢纽恢复 |
| 本地数据库（v4） | 教师端数据存**教师机 SQLite**（`data/classroom.db`）：`rooms` 表存快照与完整存档，另投影 14 张表 + 2 个统计视图；浏览器 `localStorage` 降级为兜底，断电最多丢 1 秒操作 |

## 快速开始

```powershell
npm install
npm start            # 或者直接双击「启动课堂.cmd」（会自动装依赖、起枢纽、开教师端）
```

> ⚠️ **务必用 `http://localhost:8080/admin.html` 打开教师端**，不要双击 `admin.html`。
> 直接双击是 `file://` 方式，页面拿不到本机地址，会进入**单机模式**（记分/点名/组卷/学情照常，但学生端与大屏接不进来），页面顶部会明确提示。
> 另外 `启动课堂.cmd` 必须保持**纯 ASCII**：cmd.exe 按系统代码页解析批处理，中文会拆坏命令（现已改为英文提示 + 由枢纽打印中文）。

> 🎬 **想先看效果**：`npm run demo` 会自己起一个隔离枢纽，用三个**真实页面**（教师端 / 学生端 / 大屏）走一遍
> 「建班 → 组卷 → 推题 → 入座 → 答题 → 自动判分 → 公布答案 → 抢答」，并在 [docs/demo/](docs/demo/README.md) 留下 9 张截图与实录，不需要装任何客户端。

| 端 | 地址 | 谁用 |
| --- | --- | --- |
| 教师端 | <http://localhost:8080/admin.html> | 老师（记分、组卷、点名、课堂控制、学情） |
| 学生端 | `http://<教师机IP>:8080/join` | 学生手机/平板（扫「⑦ 课堂协同」页的二维码最快） |
| 教室大屏 | <http://localhost:8080/stage> | 投影/大屏，只读实时榜 |

启动日志会打印本机可用地址；**跨网段/不同 WiFi** 时让学生设备与教师机加入同一个 EasyTier（或 ZeroTier/Tailscale）虚拟网，把虚拟网 IP 那条地址发给学生即可。

## 一节课怎么用

1. **① 班级与积分** → 「批量添加」粘贴学生名单（空格/逗号/换行分隔）并选队伍 —— 队伍就是学生端的入座身份；
2. **④ 题库与题型** → 「批量导入」粘贴题目：`题干 | 答案`（填空/主观题），选择题写 `题干 | 选项1 ; 选项2 ; 选项3 | 答案字母`；题型权重也在这一页改；
3. **② 组卷与答题** → 「新建一套题」→ 勾选题目「加入试卷」；
4. **⑦ 课堂协同** → 把二维码/地址投给学生 → 看「小组入座情况」→ 选中当前题 → **「开始接收作答」**；
5. 学生端答题/抢答；客观题当场自动加分，主观题出现在「待确认提交」，点一下「答对/部分对/答错/跳过」即写分；也可以继续用 **③ 点名** 随机抽人 + 快捷键 1/2/3/4 判分；
6. **⑤ 学情分析** → 「生成学情总结」，得到班级小结 + 每个学生的薄弱点与教学建议，可复制到群里或下载；
7. 教室大屏开着 `/stage` 即可，1 秒内同步。

> 不想走题库也可以：学生卡片上有四个题型按钮（基础题 +3 等），点一下就是"该生该题型答对"。

## 环境变量（sync-server.js）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 监听端口（HTTP 与 WebSocket 共用） |
| `HOST` | `0.0.0.0` | 监听地址 |
| `ROOM` | `default` | 默认房间号 |
| `NO_HTTP=1` | 关闭 | 只提供 WebSocket，不做静态托管 |
| `NO_PERSIST=1` | 关闭 | 不落盘（内存态运行；数据库与快照都不写） |
| `SERVE_TESTS=1` | 关闭 | 允许访问 `tests/`、`docs/`（仅供自动化测试） |
| `DATA_DIR` | `./data` | 本地数据库目录 |
| `DB_FILE` | `$DATA_DIR/classroom.db` | SQLite 文件路径（默认即教师机本地库） |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 学生端打不开 | 确认与教师机在**同一网络**（或同一 EasyTier 虚拟网）；确认地址里的 IP 用的是「⑦ 课堂协同」页显示的那条；Windows 防火墙放行该端口 |
| 教师端顶部显示"未连接枢纽" | 枢纽没启动（`npm start`），或端口被占用；此时是**单机模式**，记分照常，只是学生端/大屏收不到 |
| 大屏显示"等待数据" | 教师端还没产生数据；随便记一次分即可，或点大屏「重新请求」 |
| 学生提交没反应 | 检查教师端是否已点「开始接收作答」；同一题重复提交会被忽略（防重复计分） |
| 换了电脑没有名单 | 数据在教师机本地库：教师端顶部显示「存储：本地数据库 SQLite（classroom.db）」；迁移用「导出全部数据 / 导入备份」，或直接拷 `data/classroom.db` |
| 双击 `启动课堂.cmd` 报"不是内部或外部命令" | 该脚本曾被写成含中文的 UTF-8，cmd 按 GBK 解析会拆坏命令；现已改为**纯 ASCII + CRLF**，请勿用编辑器另存成带 BOM/中文的版本 |
| 想清空分数但保留名单和题库 | ⑥ 页签「清空全部积分」；想连试卷一起清用「恢复初始状态」 |

## 安全提示

本地枢纽**没有鉴权**，任何能访问该端口的人都能读到全班数据（含姓名），也能以任意队伍身份入座。
课堂内网使用无碍；公网暴露请自行加反向代理鉴权，并注意 `data/`、`rooms/`、`snapshot.json` 不要提交到仓库（已在 `.gitignore` 中）。
