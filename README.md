# 课堂积分系统 + 排名共享 操作文档

## 本地运行
- 安装 Node.js（18+）
- 在项目目录执行：
  - `npm init -y`
  - `npm install ws`
- 启动 WebSocket 服务：`node sync-server.js`
  - 终端显示 `ws://0.0.0.0:8080` 代表服务已启动
  - 服务端文件：`sync-server.js`（支持环境变量 `PORT`）
- 打开主页面：`课堂积分系统.html`
- 打开排行页面：`排行榜.html`

## 使用说明
- 在主页面进行积分加减、改队名、增删队伍或重置，都会自动推送最新排名到服务端并缓存
- 排行页面连接后会自动请求，收到数据后进入实时刷新；也可以点击“重新请求”按钮手动请求
- 若首次打开排行页显示“已连接”但无数据：请刷新或操作一次主页面，使服务端产生快照（之后每秒都会广播）

## 局域网/多设备
- 将两处 `WS_URL` 改为你的电脑 IP：
  - 主页面：`课堂积分系统.html:781`
  - 排行页：`排行榜.html:31`
- 示例：`ws://192.168.1.100:8080`
- 在 Windows 防火墙允许入站 8080 端口，或修改 `PORT` 使用其他端口

## 生产部署（HTTPS/公网）
- 静态托管 HTML 到任意平台（如 EO、GitHub Pages 等）
- 将 `sync-server.js` 部署到支持 Node 的平台（如 Render、Railway、云服务器），通过反向代理或平台内置证书提供 `wss://` 端点
- 将两处 `WS_URL` 改为 `wss://你的域名`，避免浏览器在 HTTPS 页面拦截非安全的 WebSocket

## 常见问题
- “已连接但无数据”：确保主页面已打开并至少进行一次积分变更；服务端会缓存并每秒广播
- 无法连接：检查 `WS_URL` 地址一致、服务端运行、端口和防火墙设置
- 多设备不刷新：确认所有设备都指向同一 `WS_URL`，且网络互通

## 安全与限制
- 当前服务为简单广播中继，无鉴权与房间隔离，适用于课堂场景；公网使用建议加鉴权
- 若需要分班/房间，请在消息体中增加房间标识并在服务端按房间转发
