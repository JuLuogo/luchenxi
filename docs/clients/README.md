## 五个可运行面

```
        ┌──────────── 三个界面（同一套 Vue 3 构建产物）────────────┐
        │  教师端 /admin.html    学生端 /join    大屏 /stage       │
        └───────────┬─────────────────────┬──────────────────┬──┘
                    │                     │                  │
        ┌───────────▼──────────┐   ┌──────▼───────┐   ┌──────▼───────┐
        │ 教师端桌面客户端(Tauri)│   │ 学生端安卓 App │   │  浏览器 / 大屏 │
        │ 内置 Rust 枢纽+SQLite │   │ 纯客户端       │   │  只读订阅      │
        └──────────────────────┘   └──────────────┘   └──────────────┘
```

- **三个界面**：`web/` 下的 Vue 3 应用（教师端 Element Plus / 学生端 Vant 移动优先 / 大屏），
  由枢纽挂在根路径提供；
- **两个壳**：`apps/teacher`（Windows/macOS/Linux）与 `apps/student`（Android），
  把**同一份 Vue 构建产物**套进 Tauri 窗口，并补上浏览器做不到的能力
  （本机 SQLite / 内置枢纽 / 组网 / 明文 HTTP）。

## 怎么把系统跑起来（截图就是这么做出来的）

```powershell
npm install
npm run web:build            # 构建 Vue 界面（产物 web/dist，按惯例不入版本库）
npm start                    # 起枢纽 + 打开教师端（也可双击「启动课堂.cmd」）

# 三端地址
# 教师端   http://localhost:8080/admin.html
# 学生端   http://<教师机IP>:8080/join?room=<房间号>
# 教室大屏 http://localhost:8080/stage?room=<房间号>
```

> 枢纽有两种实现，**协议一致**：
> `node sync-server.js`（Node 版）与 `cargo build -p ci-core --bin ci-hub-server`（**Rust 核心**）。
> 客户端内置的是 Rust 版；本目录的截图也走 Rust 版，这样学情分析页才会显示「统计来源：Rust 核心」。

## 截图与文档是怎么产出的（可复现）

本目录所有截图都是**在真实运行的界面上自动截出来的**，不是手工拼的，也不是静态假图。

| 脚本 | 作用 |
| --- | --- |
| [tests/shots-docs.js](../../tests/shots-docs.js) | 自动起**隔离枢纽**（Rust 核心 + 临时数据库 + 空闲端口）→ 灌入模拟数据 → 打开三套界面 → **按按钮文字真实点击** → 逐页截图 |
| [tests/shot-tauri.js](../../tests/shot-tauri.js) | 通过 WebView2 的远程调试端口，截取**桌面应用窗口内的真实界面**（并顺带灌入演示数据） |

```powershell
node tests/shots-docs.js                 # 三套界面全跑（44 张）
node tests/shots-docs.js --only=teacher  # 只跑教师端（student / stage 同理）

# 桌面客户端：先带调试端口启动应用，再截图
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9333'
Start-Process target\release\luchenxi-teacher.exe
node tests/shot-tauri.js 9333

# 安卓客户端：装进模拟器后用 adb 截图
adb -s 127.0.0.1:16416 install -r app-x86_64-release-signed.apk
adb -s 127.0.0.1:16416 shell screencap -p /sdcard/s.png
adb -s 127.0.0.1:16416 pull /sdcard/s.png out.png
```

截图输出在 `docs/clients/images/<客户端>/`，附 `manifest.json`（文件名 ↔ 说明）便于核对。

### 一个值得注意的规律（贯穿本轮发现的多数 bug）

v5 把旧版零构建界面删掉后，**领域层里仍有一批代码在读写那些已经不存在的 DOM 或函数**：

| 表现 | 位置 |
| --- | --- |
| `saveHost()` 去读 `#hubInput`（不存在）→ 地址存成空 | `assets/js/student.js` |
| `buzz()` 调 `toast()` 写 `#toast`（不存在）→ 抢答零反馈 | `assets/js/student.js` |
| 5 处调用 `renderHeader/renderJoin/renderTeam/renderQA`（已删除）→ 每次广播抛异常 | `assets/js/student.js` |

这类问题**静态检查发现不了**（可选参数、运行时才炸、或静默失效），
单测也覆盖不到界面层 —— **只有把界面真的点一遍才会暴露**。
建议：v5 收尾时把所有"旧 DOM 出口"集中清理一遍，或加一个"禁止再出现 `$('xxx')` 式旧 DOM 访问"的守卫测试。

> 同一类根因在**客户端**上还有第三种形态：Tauri v2 把前端挂在 `http://tauri.localhost`，
> 而代码把它当成"真实的 http 源 / 枢纽源"（`servedOverHttp()`、`servedByHub()`、窗口缺 `url` 三处）。
> 详见各篇文档的「实测发现」小节。
