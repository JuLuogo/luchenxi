## 3. 本轮自查发现的真问题（都已被测试固定）

| # | 问题 | 影响 | 修法与守护 |

## 5. 外部条件清单（这三件事本机做不了，需在别处完成）

| 事项 | 为什么本机做不了 | 怎么完成 |
| --- | --- | --- |
| Rust 编译与客户端出包 | 本机无 `cargo`，也无 MSVC/MinGW 链接器（已探测：`link`/`cl`/`gcc`/`clang` 全无） | ① 装 rustup + MSVC 生成工具后 `npm run ci`（会自动加上 `cargo test`）；② 或 `git push` 让 `rust.yml`/`build.yml` 跑 |
| Android 签名与真机 | 无 JDK/Android SDK，且需要 keystore | CI 里配 `secrets`（keystore）后 `build.yml` 产出 APK；真机验证手输地址与答题 |
| EasyTier 实机组网 | 需要两台设备与管理员权限 | 按 `apps/README.md` 的组网步骤，先在教师机 `一键组网`，再用官方 App 让手机加入 |

## 6. 已知差异与限制（不是 bug，是取舍）

- **客户端没有 `/qr.png`**：二维码降级为文字地址（可复制）。后续可选在 Rust 侧引入 `qrcode` crate 补齐。
- **Android 不能内置 EasyTier**：官方 Android 只有 GUI APK、无 CLI，只能引导装官方 App。
- **枢纽无鉴权**：课堂内网可接受；公网暴露需自行加反代鉴权（`docs/11 §8.3`）。
- **iOS 只做编译检查**：真正出包需 Apple 开发者证书。
- **窗口必须保持 `useHttpsScheme: false`**：两个客户端都已显式设置。若改成 `true`，origin 变成 `https://tauri.localhost`，WebView 会以"混合内容"为由禁止连 `ws://教师机IP:8080`（见 tauri-apps/tauri#7651），学生会一直连不上。
- **Android 明文流量必须放行**：Android 9+ 默认禁止明文，而学生端连的是局域网 `ws://`。由 `scripts/patch-android-manifest.mjs` 在打包前改清单（Tauri 配置里无此开关）；真机验证时若"装了但连不上"，先查这一条。
- **多写者只做了"过期拒绝"**：没有做字段级合并（同一时刻两台机器都改，晚提交的更旧会被拒，需要人工拉取最新）。
