# 08 · 开发、部署与测试

> v3 的部署形态变了：**不再需要公网服务器**。教师机跑一个本地枢纽（`sync-server.js`），教师端 / 学生端 / 大屏 / 二维码全部由它托管，学生用手机连教师机 IP 即可。
>
> 本文讲**怎么跑、怎么部署、怎么测**。为什么这么设计见 [10 多端协同架构](10-多端协同架构.md)，报文格式见 [07 通信协议与 API](07-通信协议与API.md)。

## 1. 环境要求

> ⚠️ **Node 版本**：枢纽的 SQLite 用内置 `node:sqlite`，它在 **Node 22.x 仍需要 `--experimental-sqlite`**，
> Node 24 起默认可用。CI 与推荐环境都用 **Node 24**；用旧版 Node 时枢纽会自动退回 `rooms/*.json`（功能可用，但不是数据库）。

| 项 | 要求 |
| --- | --- |
| Node.js | 18+（开发机实测 24.x）。只有枢纽需要 Node，学生端/大屏/教师端都是纯静态页面 |
| 依赖 | `ws`（WebSocket 服务端）+ `qrcode`（二维码，建议装：不装则 `/qr.png` 返回 501，界面自动降级为文字地址）—— 见 `package.json:14-17` |
| 浏览器 | Chrome / Edge / Safari 现代版本（使用 `const/let`、模板串、`fetch`；刻意规避 `?.`、`??`，兼容较老的 iPad） |
| 构建 | **无**。改完文件刷新页面即生效（无打包器、无 ES Module，脚本按固定顺序 `<script src>` 加载） |
| 网络 | 教师机与学生设备需互相可达：同一局域网，或已加入同一个 EasyTier/ZeroTier/Tailscale 虚拟网 |

## 2. 三分钟跑起来（推荐路径）

```powershell
npm install          # 首次：装 ws 与 qrcode
npm start            # 等价于 node sync-server.js；Windows 也可双击「启动课堂.cmd」
```

`启动课堂.cmd` 会做三件事：依赖自检（缺 `node_modules\ws` 才装）、在**独立窗口**启动枢纽、3 秒后打开教师端页面。

> ⚠️ **这个 .cmd 必须保持纯 ASCII + CRLF**：cmd.exe 按系统 ANSI 代码页解析批处理，UTF-8 中文的字节序列可能含 `|`/`&` 而被当成命令分隔符拆行（曾导致双击后满屏「不是内部或外部命令」）。中文提示交给枢纽进程打印（Node 输出在 `chcp 65001` 下正常显示）。改完用 `cmd /c tests\cmd-smoke.cmd` 验证启动器结构。

启动日志（`sync-server.js:400-411`）：

```

  学生端 : http://192.168.0.180:8080/join    ← 学生手机/平板输入这个地址（或用 EasyTier 虚拟 IP）
  大屏   : http://localhost:8080/stage
  房间   : default（教师端可改；学生端用 ?room=xxx 进入指定房间）
  二维码 : 可用（/qr.png?text=…）
```

| 谁 | 打开什么 | 说明 |
| --- | --- | --- |
| 教师端 | `http://localhost:8080/admin.html`（或 `/`） | **零配置**：地址留空即「与页面同源」，自动连本机枢纽 |
| 学生端 | `http://<教师机IP>:8080/join` | 手机/平板；也可扫「⑦ 课堂协同」页的二维码 |
| 教室大屏 | `http://localhost:8080/stage`（或 `/big`、`/screen`） | 投屏电脑打开后按 F11 全屏 |

### 2.1 为什么教师端是零配置

教师端把「同步地址」存在 `localStorage['ci_ws_host']`，**空值表示与页面同源**（`sync.js:16-19`）。教师机用 `http://localhost:8080/admin.html` 打开时，页面本身就来自枢纽，于是 WebSocket 直接连 `ws://localhost:8080/`，不需要填任何地址 —— 这正是「教师机即服务器」的落地方式。

> 只有在**页面与枢纽不同源**时（例如教师端放在静态托管上、枢纽在另一台机器）才需要填地址，见 §4.1。

### 2.2 课堂部署清单（教师机）

1. 教师机运行 `npm start` 或双击 `启动课堂.cmd`；
2. 放行防火墙入站 TCP（首次运行 Node 时 Windows 也会弹窗，勾选「专用网络」即可）：

   ```powershell
   New-NetFirewallRule -DisplayName "课堂积分8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
   ```

3. 教师端「⑦ 课堂协同」确认房间号、学生端地址与二维码（装了 `qrcode` 才会显示二维码）；
4. 学生扫码或输入地址 → 点自己小组入座（队伍即身份）；
5. 教师端「② 组卷与答题」选中题目 → 「⑦ 课堂协同 → 开始接收作答」→ 学生端出现题目与选项；
6. 教室大屏电脑打开 `http://localhost:8080/stage`。

## 3. 跨网络（不同网段 / 手机热点 / 校外）

教师机与学生不在同一局域网时，用**组网工具**把它们放进同一个虚拟网络（推荐 EasyTier，同类可选 ZeroTier / Tailscale / WireGuard）：

1. 教师机与学生设备都加入同一个虚拟网络；
2. 教师机执行 `ipconfig` 找到虚拟网卡地址（常见 `10.x.x.x`）；
3. 教师端「⑦ 课堂协同」会列出本机**全部可用地址**（`/health` 的 `ips`，私网地址优先，`sync-server.js:322-334`），把虚拟网地址那条发给学生，或直接用该地址的二维码；
4. 若学生仍然连不上，检查教师机防火墙是否放行了该端口。

> 枢纽只监听 `0.0.0.0:<端口>`，不主动外联，**没有任何公网依赖**：能不能连上完全取决于学生设备能否路由到教师机。

## 4. 其它部署形态

### 4.1 静态托管 + 远程枢纽（v2 老形态，仍可用）

把 `admin.html`、`student.html`、`index.html`、`assets/` 上传到任意静态托管（GitHub Pages / EdgeOne / Nginx），`sync-server.js` 单独部署到一台可达的机器（支持 Node + WebSocket 即可），然后：

- 教师端页签⑥「大屏同步服务器」填 `wss://你的域名`（HTTPS 页面里必须 `wss://`，`admin.js:374-380`）；
- 学生端与大屏用 `?ws=host:port` 参数或 `localStorage['ci_ws_host']` 指定枢纽（`index.html:113-125`）。

代价：多一跳公网依赖，且枢纽**无鉴权**，公网暴露必须自行加反代鉴权（Basic Auth / Token）。

### 4.2 无枢纽：单机模式

直接双击 `admin.html`（`file://`）也能用：记分、组卷、点名、学情全部功能不受影响，只是学生端与大屏收不到数据。

- `file://` 下页面没有 host，`sync.js` 的 `url()` 会返回 `null`，于是**不会发起连接、也不会重连**，顶部提示为「单机模式：当前以本地文件打开，学生端无法接入 —— 需要多端协同时请运行「启动课堂.cmd」，再用 http://localhost:8080/admin.html 打开本页」（`sync.js:89-96`）；
- 枢纽**启动过但已经停掉**时提示为「与枢纽断开，重试中…（单机模式仍可继续记分）」，并指数退避重连（`sync.js:166-167`、`sync.js:177-184`）；
- ⑦ 课堂协同页两种情况都显示「未连接枢纽（单机模式：学生端无法参与，教师端功能不受影响）」，且「学生端地址」显示 `（未连接枢纽）` 并给出切换指引（`classroom.js:376-410`）。

> 单机模式下数据只在浏览器 `localStorage`，换设备/清缓存前务必「导出全部数据」。

### 4.3 生产/长期使用注意

| 项 | 建议 |
| --- | --- |
| 鉴权 | 枢纽无鉴权，`hello` 还能把连接改成 `host`：公网暴露必须加反代 Basic Auth / Token，或只在内网使用 |
| 持久化 | `rooms/` 必须放在可写且**不随部署清空**的磁盘上（`NO_PERSIST=1` 会关掉落盘） |
| 磁盘清理 | `rooms/<房间>.json` 是**运行时产物**：每上过一个新房间就多一个文件，且含学生姓名与成绩。已加入 `.gitignore`（`.gitignore:29-31`），可随时安全删除（枢纽会重新建） |
| 端口 | 用 `PORT` 指定；端口被占用时枢纽打印中文提示并 `exit 1`（`sync-server.js:389-398`） |
| 数据主库 | 教师端浏览器才是主库，枢纽的 `rooms/` 只是缓存副本 |

## 5. 环境变量

| 变量 | 默认 | 作用 | 位置 |
| --- | --- | --- | --- |
| `PORT` | `8080` | 监听端口 | `sync-server.js:26` |
| `HOST` | `0.0.0.0` | 监听地址 | `sync-server.js:27` |
| `ROOM` | `default` | 默认房间 id（客户端没带 `?room=` 时用它） | `sync-server.js:30` |
| `NO_PERSIST=1` | 关闭 | 不读写 `rooms/*.json`（纯内存，重启即空） | `sync-server.js:31` |
| `NO_HTTP=1` | 关闭 | 不做静态托管，只提供 WS（+ `/health`、`/qr.png`） | `sync-server.js:32` |
| `SERVE_TESTS=1` | 关闭 | 额外托管 `tests/` 与 `docs/`，**只给自动化测试与截图用** | `sync-server.js:33` |

```powershell
# 换端口（同时要把教师端页签⑥的同步地址改掉，或直接用同源地址）
$env:PORT=8090; npm start
```

### 7.2 端到端的前置条件（最容易踩的坑）

端到端用例本身是网页（`tests/smoke.html`、`tests/smoke-class.html`），必须由枢纽托管，而枢纽**默认拒绝 `tests/` 目录**（`sync-server.js:372-382`）。所以：

```powershell
# 终端 A：测试用枢纽（必须在 8123，且必须 SERVE_TESTS=1）
$env:PORT=8123; $env:SERVE_TESTS=1; node sync-server.js

# 终端 B：
npm run test:e2e
npm run test:e2e:class     # 两条 e2e 都占用 CDP 9333 端口，必须串行跑
```

`npm run test:e2e:class` 的脚本里已写死 `http://127.0.0.1:8123/tests/smoke-class.html`（`package.json:10`），所以端口不能随便换。

### 7.4 写用例时的四个坑（已处理，勿踩）

1. **无头浏览器会阻塞在 `confirm/alert/prompt`**：`smoke*.html` 在驱动前把 `window.confirm/alert/prompt` 替换为桩函数；`run-smoke.js` 另外监听 `Page.javascriptDialogOpening` 自动接受兜底（`tests/run-smoke.js:119-127`）。自己写用例务必照做，否则渲染进程卡死，表现为 `Runtime.evaluate` 超时。
2. **界面渲染有 30ms 防抖**：状态变更后要 `await wait(250)` 再断言 DOM（`admin.js:519-522`）。
3. **多端用例要等异步链路**：学生提交 → 枢纽转发 → 教师端判分 → 快照回推 → 大屏渲染是五个异步跳，断言前用轮询而不是固定 `sleep`（`tests/smoke-class.html:45-54` 的 `until()`）。
4. **dump 通道有 15s 节流**：教师端的完整课堂数据最多每 15s 推一次（被节流时会预约一次补发，见 `sync.js:287-315`）。测试里要立刻读到最新 dump，就显式调 `CI.sync.pushDump(true)` 强制推一次（`tests/smoke-class.html:185-187`），否则要么等 15s，要么读到旧数据。
5. **多端用例要用独立房间**：`smoke-class.html` 每次运行都生成 `smokeclass-<时间戳>` 作为房间号（`tests/smoke-class.html:29-30`），避免读到上次运行残留在枢纽里的课堂数据。自己写用例时照做，或先清掉 `rooms/`。

> 想用静态计数核对断言条数时注意：`smoke*.html` 里 `check(` 的出现次数比运行时断言数**多 1**（`function check(cond, label)` 定义那一行也会被匹配）。

## 8. 常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| 学生手机打不开 `/join` | ①不在同一网络（先确认与教师机同 WiFi，或都已加入同一个 EasyTier 虚拟网）；②防火墙没放行端口；③教师机有多个网卡，换「⑦ 课堂协同」里列出的其它地址试 |
| 二维码显示不出来 | 未安装 `qrcode`（`/qr.png` 返回 501）；执行 `npm i qrcode` 后刷新页面。界面会自动降级为文字地址，不影响使用 |
| 学生端一直显示「等待老师端推送名单…」 | 教师端还没连上枢纽，或班级里还没有队伍；先在教师端①建队伍并确认协同页显示「已连接枢纽」 |
| 学生端能入座但看不到题目 | 教师端没有「开始接收作答」，或没设当前题（`runtime.qid`）；协同页会显示当前题与开关状态 |
| 学生提交了但没加分 | ①客观题答错（不加分）；②主观题进「待确认」等老师判定；③教师端离线，命令在枢纽排队，联网后自动补发（学生端会提示，教师端上线时提示「已补收 N 条离线提交」） |
| 老师换了电脑 / 清了缓存 | 教师端重连枢纽后若本机为空，会弹窗提示「枢纽上有一份课堂数据，是否载入？」（`admin.js:524-534`）；选取消则从空白开始并覆盖枢纽 |
| 大屏一直「等待数据」 | 教师端未打开或从未产生数据；打开教师端点一次分即可。也可点大屏「重新请求」 |
| 顶部显示「与枢纽断开，重试中…」 | 地址不对 / 枢纽未启动 / 防火墙拦截；教师端页签⑥确认地址与协议（HTTPS 页面必须 `wss://`） |
| 端口被占用 | 枢纽打印「端口 8080 已被占用…」并退出；换端口：`$env:PORT=8090; npm start`，并同步修改页签⑥的地址 |
| 换电脑后没有名单 | 数据在浏览器 localStorage，新设备需「导入备份」（页签⑥）或从枢纽的 `dump` 恢复 |
| `rooms/` 出现在 git 状态里 | 已在 `.gitignore` 中忽略（`.gitignore:31`）；若曾被提交过，用 `git rm -r --cached rooms` 移除 |
| 枢纽里攒了一堆房间文件 | `rooms/<房间>.json` 是运行时缓存，含学生姓名与成绩；停掉枢纽后整个目录可安全删除 |
| 两条 e2e 一起跑就失败 | `run-smoke.js` 与 `probe.js`/`shot.js` 各占一个 CDP 端口，但 e2e 的两个用例都用 9333；**串行执行**，别并行 |
| 端到端测试页 404 | 枢纽没带 `SERVE_TESTS=1`（默认拒绝托管 `tests/`） |
| **双击 `启动课堂.cmd` 报一堆「不是内部或外部命令」** | 该文件必须保持**纯 ASCII + CRLF**：cmd.exe 按系统 ANSI 代码页解析 `.cmd`，UTF-8 中文的字节序列里可能含 `\|`/`&` 等，会被当成命令分隔符而拆行（本仓库曾因此踩坑，现已改为英文提示 + 由枢纽打印中文）。**任何编辑器另存时都不要给它加 BOM、不要引入中文**；改完用 `cmd /c tests\cmd-smoke.cmd` 验证（该脚本用一次性端口 8199 复刻启动器结构，跑完自动清理） |
| 枢纽窗口一闪而过 / 提示缺 `ws` | 依赖没装全：`npm install`；枢纽对缺失 `ws` 有友好提示（不会甩堆栈）。启动器用 `if not exist node_modules\ws` 判断并自动安装 |
| **双击 `admin.html`（file://）后顶部写「单机模式」** | 预期行为：`file://` 下页面没有 host，连不上教师机枢纽，学生端与大屏自然接不进来。记分/点名/组卷/学情全部照常。**需要多端协同时请改走 `http://localhost:8080/admin.html`**（先运行启动器或 `npm start`）；⑦ 页也会给出同样的提示 |
| 打开教师端后 ⑦ 页「学生端地址」显示 `（未连接枢纽）` | 同上：页面不是由枢纽提供的，或枢纽没启动。先起枢纽，再用 `http://localhost:8080/admin.html` 打开 |
| `timeout` 报「Input redirection is not supported」 | 只会在把启动脚本的输出重定向（非交互式）时出现；启动器已改用 `ping -n 4 127.0.0.1 >nul` 延时，正常双击不受影响 |
| **下载 EasyTier sidecar 失败（证书/代理）** | 报 `UNABLE_TO_VERIFY_LEAF_SIGNATURE` 之类说明本机有 TLS 拦截代理：设 `NODE_EXTRA_CA_CERTS` 指向企业根证书，或走镜像 `EASYTIER_MIRROR=https://ghfast.top/ node scripts/fetch-easytier.mjs <target>`，或离线下载后 `node scripts/fetch-easytier.mjs --from <压缩包> <target>`。GitHub Actions 里通常直连可用 |
| Tauri 构建报找不到 externalBin | `apps/teacher/src-tauri/binaries/` 里没有 sidecar：先跑 `npm run easytier`；开发模式（`tauri dev`）不校验打包资源 |
| 客户端里「存储」显示 localStorage 而不是 SQLite | 客户端环境下应由 `invoke('db_load')` 直连 SQLite；若回退说明命令调用失败（看界面提示的「最近写入异常」）。浏览器里则需要枢纽在跑（`/health` 显示 `"storage":"sqlite"`） |

## 9. 发布流程建议

1. 本地跑 `npm test`（必须全绿：153 项断言 + 接线自检）；
2. 起测试枢纽（`$env:PORT=8123; $env:SERVE_TESTS=1; node sync-server.js`），跑 `npm run test:e2e`（52/52）与 `npm run test:e2e:class`（45/45）；
3. `node tests/doc-refs.js --broken` 复核文档引用（应为 0 越界）；
4. 更新 [09 变更记录](09-路线图与变更记录.md)；
5. 需要新配图时 `npm run screenshots` 并提交 `docs/screenshots/`；
6. 分发时**不要带** `rooms/`、`snapshot.json`（含学生姓名与成绩）；
7. 课堂前用真机走一遍 [09 §6 验收清单](09-路线图与变更记录.md#6-已交付功能的验收清单) 的「多端协同」部分。
