## 4. 已知限制

| 分类 | 限制 | 说明/规避 |
| --- | --- | --- |
| 数据 | 主库在教师端浏览器 localStorage，换设备/清缓存即丢 | 每节课后「导出全部数据」；枢纽的 `rooms/` 只是缓存副本，可用 `dump` 恢复 |
| 数据 | 删除试卷会连带删除该试卷的积分流水 | 删除前先「导出本套流水」 |
| 统计 | 手动 ±分不进入题型统计 | 有意为之：手动分不携带题型信息 |
| 统计 | 快捷题型加分默认按「答对一次」计入统计 | 可在计分口径设置里关闭（`quickCountsAsAttempt`） |
| 统计 | 知识点靠 `tags` 字符串匹配，没有独立知识点表 | 改名需同步题目；批量改名建议导出 JSON 后统一替换再导入 |
| 统计 | `studentStats` 为 O(学生数 × 流水数) | 课堂规模无感，破万条流水需改聚合方式（P1） |
| 点名 | 修改模式/范围会清空轮次池 | 有意为之：范围变化后「本轮」不再成立 |
| 点名 | 防连点是「最近 N 次」而非整轮 | 需要整轮不重复请用 `even` 模式 |
| 点名 | 点名历史存在教师端，多设备不互通 | 只有教师端可以点名 |
| 协同 | 枢纽**无鉴权**，`hello` 还能把连接改成 host；房间号可猜 | 课堂内网可接受；公网暴露必须加反代鉴权（[10 §8](10-多端协同架构.md#8-安全边界课堂场景的取舍)） |
| 协同 | 单写者模型：两台教师端同时打开会互相覆盖 | 约定「一台机器记分，其它设备只看大屏」 |
| 协同 | 枢纽重启会丢「未补发的离线命令队列」与在线状态 | 已判定的分数早已进教师端 `store`，不受影响；学生重连后重新入座 |
| 协同 | 学生可任选队伍入座（队伍即身份） | 零登录成本的取舍；教师端在线面板可见每队入座情况 |
| 协同 | 学生端断线后未提交的答案不会自动重发 | 学生自己重发，避免重复计分（[10 §5](10-多端协同架构.md#5-权威与容错)） |
| 运维 | `rooms/<房间>.json` 每个房间一个文件，长期使用会积累，且含学生姓名与成绩 | 已加入 `.gitignore`（`.gitignore:29-31`）；停掉枢纽后可整目录删除，枢纽会按需重建 |
| 兼容 | 未在 Safari/老 iPad 上做过自动化验证 | 发版前人工过一遍（已规避 `?.`/`??`） |
| 兼容 | 无离线缓存 / PWA | 断网时教师端仍可用（单机模式），但学生端与大屏无法更新 |

- [ ] 「计分口径设置」把部分正确系数改为 0.4 → 部分正确得分为 基准 × 0.4；
- [ ] 点「撤销上一步」→ 分数回退且日志出现「撤销」。

### 6.2 题库与组卷（F2/F3）

- [ ] 页签②「新建一套题」→ 勾选 2 题加入 → 「设为当前题」→ 选学生 → 点「答对」→ 学生加分、流水出现一行；

### 6.3 点名（F5）

- [ ] 勾选「排除当前题已作答」→ 已答过当前题的学生不再被抽到；
- [ ] 点「答对」→ 该生按当前题基准分加分，点名记录里显示判定结果；

### 6.4 学情分析（F4）

### 6.5 大屏与容错（F6/F7）

### 6.6 多端协同（F8–F16，v3 新增）

**部署与连接**

- [ ] 教师机 `npm start`（或双击 `启动课堂.cmd`）→ 教师端 `http://localhost:8080/admin.html` 顶部显示「已连接枢纽 · 房间 default」，**没有填任何地址**；
- [ ] 学生手机浏览器打开 `http://<教师机IP>:8080/join` → 能看到班级的小组列表；
- [ ] 「⑦ 课堂协同」页显示房间号、学生端地址、二维码（装了 `qrcode` 时），点「复制地址」能拿到可粘贴的 URL；
- [ ] 教室大屏 `http://localhost:8080/stage` 显示课程名与榜单。

**入座与在线状态**

- [ ] 学生端点自己小组 → 教师端「小组入座情况」该组变「在线」，大屏显示「实时同步 · 1 组在线」；
- [ ] 学生端刷新页面 → 自动回到原小组（`localStorage['ci_team']`）；
- [ ] 学生端双击顶栏 → 回到小组选择页，可换组。

**答题与判分**

- [ ] 教师端②选中一道**选择题** → ⑦点「开始接收作答」→ 学生端出现题干与选项，且按钮可用；
- [ ] 学生选对答案提交 → 教师端实时流出现「答对（+3）」、该生加分、队伍分同步增加、大屏 1 秒内变化、学生端显示「已提交：答对 +3」；
- [ ] 学生故意选错 → 不加分，实时流显示「答错」；
- [ ] 多选题：漏选（真子集）判「部分正确」，按 `halfRatio` 记分；
- [ ] **填空题**：答案写成 `8`，学生输入全角 `８` 或带空格也能判对；答案写 `8|八|eight` 三种写法都判对；
- [ ] 同一队重复提交同一题 → 教师端提示「重复提交，已忽略」，分数只加一次；
- [ ] 教师端点「停止接收作答」→ 学生端提交按钮变为禁用并显示「未开放作答」；
- [ ] 点「公布答案」→ 学生端显示正确选项高亮 / 参考答案，教师端按钮变「隐藏答案」；
- [ ] **不切页签推题**：在 ⑦ 直接点「下一题 →」→ 学生端与大屏立即换成下一题，教师端「第 2 / m 题」进度更新；
- [ ] **换题后答案收起**：公布第一题答案后点「下一题」→ 第二题**不会**显示答案（`runtime.revealedQid` 机制），大屏的「答案」标签也消失；
- [ ] 第一题处点「← 上一题」不会越界（按钮置灰）；
- [ ] 关掉枢纽进程（或拔网线）后教师端仍可记分、点名、组卷、看学情，⑦ 页显示「未连接枢纽（单机模式…）」，页面不白屏。

**主观题与抢答**

- [ ] 当前题为**主观题**（无选项、无答案）→ 学生提交后进入教师端「待确认提交」队列，**此时不加分**；
- [ ] 教师点「答对」→ 该生按题型权重加分，队列清空，实时流出现「教师判定：答对（+5）」；点「丢弃」则不记分；
- [ ] 学生点「⚡ 抢答」→ 教师端「抢答榜」按时间排序显示队伍；同一队重复抢答只记一次；
- [ ] 「抢答榜」点「设为当前学生」→ 顶部「当前学生」变为该队成员，方便接着点名判分。

**容错**

- [ ] 上课中途关掉教师端页面 → 学生提交时提示「老师端离线，已排队」；重开教师端后提示「已补收 N 条离线提交」，分数补上；
- [ ] 上课中途重启枢纽 → 学生端与大屏自动重连并立刻显示数据（来自 `rooms/<房间>.json`）；
- [ ] 教师端换一台电脑打开（本机无数据）→ 提示「枢纽上有一份课堂数据，是否载入？」，选载入后名单、分数、待确认提交都在；
- [ ] 改房间号 → 学生端地址与二维码同步更新，旧房间的学生端收不到新数据。
